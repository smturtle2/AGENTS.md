`gpt-6-astra` 이상의 모델에 적용하는 AGENTS.md를 관리하는 저장소입니다.

에이전트가 충분한 조사와 근거를 바탕으로 판단하고, 작업 중 발견한 책임 구조의 문제를 적극적으로 바로잡으며, 검증과 통합까지 수행하도록 작업 원칙을 정의합니다.

전체 지침은 [AGENTS.md](AGENTS.md)에서 확인할 수 있습니다.

## 설계 방향

| 원칙 | 지침이 요구하는 행동 |
| :--- | :--- |
| **조사에 기반한 판단** | 접근 방식을 정하기 전에 충분히 조사하고, 작업의 불확실성과 영향에 맞춰 조사 범위와 깊이를 조절합니다. |
| **명확한 책임 구조** | 흩어진 책임은 통합하고 뒤섞인 관심사는 분리하며, 코드의 겉모양보다 변경 이유를 기준으로 경계를 정합니다. |
| **구조까지 포함하는 해결** | 책임이 있는 위치에서 원인을 해결하고, 필요한 구조 수정까지 작업에 포함합니다. |
| **난도에 맞는 위임** | 상당한 추론과 판단은 직접 수행하고, 추론 부담이 낮고 독립 검증이 쉬운 작업을 Luna에 위임합니다. |
| **검증과 통합** | 근거와 실제 동작을 확인하고, 위임한 작업까지 일관된 결과로 통합합니다. |

## 구성

- **문제 해결** — 사전 조사, 책임 구성, 원인과 구조의 수정
- **에이전트 운영** — Luna 작업 선택, 병렬 수행, 인계와 검증
- **사용자 소통** — 호칭과 대화 모드
- **개발 규칙** — Python 환경, Git 작업, 관리자 권한 명령 실행

## 적용 범위

이 저장소의 지침은 GPT-6 Astra 이상의 모델을 대상으로 합니다. Luna 관련 항목은 해당 모델이 Luna 서브에이전트에 작업을 위임할 때의 운영 규칙입니다.

대화창 스킬, `uv`, `run0` 등 특정 도구를 사용하는 규칙도 포함되어 있습니다. 실제 적용 시에는 사용하는 환경과 소통 방식에 맞게 조정하세요.
